# Na Croatia website

This is website for croatian Narcotics Anonymous (NA) fellowship. NA is a nonprofit fellowship or society of men and women for whom drugs had become a major problem. Only requirement for membership is a desire to stop using.
NA Croatia organizes meetings where members can meet regulary to help each other stay clean.

This website shows basic information about where and when meetings are organized. This is crutial information that should be displayed on the first version of the site, along with information that the new web is currently under construction.

Web should be SEO optimized, so search engines can quickly index page so newcomers can find us if they ever get lost in Zagreb, Croatia.

For the first version only one, root, landing page.

## Meetings

### Location

Crkva sv. Blaža, Prilaz Gjure Deželića 64, Zagreb

Tuesdays 7PM (Croatian)
Thursdays 7PM (English)
Saturdays 12PM (Croatian)

Online meetings every monday 9PM via Microsoft Teams (link: https://teams.live.com/meet/9390459011004?p=cq5L47cb1sOWoS3Pjs)
